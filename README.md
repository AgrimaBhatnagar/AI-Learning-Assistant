# AI-Powered Learning Assistant

A Retrieval-Augmented Generation (RAG) platform that helps students discover learning resources, generate summaries, answer academic questions, and receive personalized study recommendations.

## Features

- Document Question Answering
- Context-Aware Retrieval
- Academic Summarization
- Personalized Learning Recommendations
- AI-Powered Guidance

## Tech Stack

- Python
- Flask
- Vue.js
- Redis
- RAG
- LLMs
